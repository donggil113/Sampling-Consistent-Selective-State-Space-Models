# Anonymous review package: "Where Sampling-Grid Dependence Enters Selective State-Space Models"

This package supports the anonymous review of the manuscript. `MANIFEST.sha256` lists every file.

- **Style.** The manuscript uses the official ICML 2026 style (unmodified), because no official 2027 style had been published when it was prepared. The target is ICML 2027.
- **Status.** The manuscript is not marked submission-ready.
- **License.** No license file is included. The authors will state the license at release.

## Included

| Path | Content |
|---|---|
| `paper/main.tex`, `paper/generated/`, `paper/references.bib` | Manuscript source. Every table, figure and number is generated by `scripts/make_paper_assets.py` from `results/raw/` and `run_manifest.json`. |
| `paper/main.pdf` | Built manuscript. |
| `configs/` | Pre-registered configurations for every run, written before each run was executed. |
| `src/scssm/` | Toy model, grids, RK4 references, metrics, cascade check. |
| `src/scssm/real/` | TIDES adapter, protocol, bootstrap helpers. |
| `scripts/` | Runners, convention check, adapter check, layer diagnostic, H8 decomposition, table generator, build script. |
| `tests/` | Unit tests. |
| `results/raw/` | Raw records for the toy runs (`FR-*.jsonl`), the cascade check (`P1-COMP-01.jsonl`), the development run (`P1-REAL-01.jsonl`, `P1-REAL-01__summary.json`, `P1-REAL-01__convention_check.json`), the seed repetition (`results/raw/P1-REAL-02/seed{1..4}/eval.jsonl` plus summaries and training logs) and the H8 decomposition (`results/raw/P1-REAL-02/h8_decomposition/`, including per-token outputs as gzip JSON). |
| `run_manifest.json` | Environment, data and test-set hashes, checkpoint sha256, and wall and CPU seconds of every run. |

**Sanitization.** Commit identifiers of the authors' repository and absolute local paths were replaced by `<commit>` and `<repo>`/`<tmp>` in the text files. No numerical value was changed.

## Not included

- **Model checkpoints.**
  - Regenerate them with `python3 scripts/run_p1_real_02.py --stage train --seed s` for s in 1–4, after the `data` stage.
  - The development checkpoint is regenerated by `python3 scripts/run_p1_real_01.py --stage train`.
  - Their sha256 values are in `run_manifest.json`.
  - A retrain of the development seed reproduced every tensor.
- **Third-party TIDES code** (MIT license).
  - Clone the official repository into `third_party/TIDES` and check out commit `4b51adce2060e7209e002a6a2fd6691a2f6fcc5e`.
  - It is used unmodified through `src/scssm/real/tides_adapter.py`.
- **Cached synthetic data.** The data and test set are regenerated by the `data` and `testset` stages. Compare their sha256 with `results/raw/P1-REAL-02/data_hash.json` and `testset_hash.json`.
- **ICML style files.** `scripts/build_paper.sh` fetches the official kit and checks its sha256.

## Reproduce

Environment used: Python 3.11, torch 2.14.0+cpu, numpy 2.4.6, scipy 1.17.1, 2 CPU threads, TeX Live with latexmk.

```bash
python3 -m unittest discover -s tests -t .
python3 scripts/make_paper_assets.py          # regenerates paper/generated/ from results/raw/
scripts/build_paper.sh                        # builds paper/main.pdf with the official style
# trained-model runs (need third_party/TIDES):
python3 scripts/run_p1_real_02.py --stage data && python3 scripts/run_p1_real_02.py --stage testset
for s in 1 2 3 4; do python3 scripts/run_p1_real_02.py --stage train --seed $s; python3 scripts/run_p1_real_02.py --stage eval --seed $s; done
python3 scripts/run_p1_real_02.py --stage aggregate
python3 scripts/derive_h8_decomposition.py     # one frozen forward per checkpoint
```

Timing values depend on the machine.
