\begin{abstract}
Selective state-space models (SSMs) compute their discretization step from the input, so the same physical signal observed on a different time grid can yield a different output.
We ask where this grid dependence enters and how much of it is an artifact rather than new information.
In fixed-parameter continuous-time toys we separate \emph{interval splitting}, which leaves the held input path unchanged, from the \emph{addition of new observations}, and we measure four entry points: a step size that ignores elapsed time, the discretization of the input matrix, sample-count readouts, and the resampling of internal signals between layers.
A step proportional to elapsed time, an exact zero-order-hold input matrix and an exact time-integral readout together remove the single-layer splitting artifact to float64 precision, whereas no single fix does; in a two-layer linear cascade, holding the layer-1 endpoint at layer~2 leaves a first-order error (\CompErrOne{} at the base step, \CompErrEight{} after eight-fold splitting) although no external information is added.
We propose no new architecture, and evaluations of trained models are pending (\todo{P1-REAL-01: trained official TIDES, native grid vs.\ training-grid resampling}).
\end{abstract}

\section{Introduction}
\label{sec:intro}

Continuous-time state-space layers are usually applied to sequences by discretizing a linear ODE over each interval between observations.
When the step size is the physical elapsed time, the discrete recurrence inherits the semantics of the continuous system, which is what allows S4, LSSL and S5 to change the sampling rate at test time or to consume irregular timestamps~\citep{gu2021s4,gu2021lssl,smith2022s5}.
Selective SSMs such as Mamba instead compute the step $\Delta$ from the current token~\citep{gu2023mamba,dao2024mamba2}.
The step then acts as a content gate, and a change of the time grid can change the output even when the underlying signal is the same.
Recent work makes this point directly and proposes an architecture that keeps $\Delta$ physical while moving selectivity to the state matrix~\citep{soydan2026tides}.

This paper does not propose another architecture.
It asks a narrower measurement question: \emph{when only the time grid of the same physical input path is changed, where in a selective SSM does the output change enter, and which of those changes are artifacts?}
Answering it requires separating two operations that are often conflated.
\emph{Splitting} a held interval into $m$ sub-steps that repeat the held value leaves the physical input path unchanged, so any output change is an artifact.
\emph{Adding new observations} of the same continuous signal changes the reconstructed input path, so part of the output change is genuine new information.

\paragraph{What is already known and not claimed here.}
Using the physical $\Delta t$ in the discretization, exact zero-order-hold (ZOH) formulas, and the flow-composition law behind split invariance are standard~\citep{gu2021lssl,smith2022s5}.
That the released Mamba code approximates the input matrix by $\bar B=\Delta B$ (``exponential-Euler'') rather than the ZOH formula stated in the paper is documented by \citet{lahoti2026mamba3}.
That a continuous-time reading of selective SSMs requires $\Delta\propto dt$ is shown by \citet{cirone2024theoretical}.
Keeping $\Delta$ physical and placing selectivity on the decay rate is the design of \citet{soydan2026tides}.
We use these facts; we do not count them as contributions.

\paragraph{Contributions.}
All contributions are measurements or analyses in controlled toys; none is an architecture.
\begin{enumerate}
  \item A measurement protocol that separates splitting from new observations and decomposes the output change exactly into a path term and an artifact term, with explicit denominators (\cref{sec:setup}).
  \item Controlled single-layer measurements of four entry points (step scaling, input-matrix discretization, stiffness, readout), including the interaction of fixes: each fix alone leaves at least half of the change (\cref{sec:exp}).
  \item An explicit statement and check of inter-layer coupling: with the physical step and exact ZOH in every layer, a layerwise computation that holds internal endpoint values still changes under splitting, at first order in the step, without any new external information (\cref{sec:coupling,sec:exp-coupling}).
  \item A pre-specified evaluation protocol for one official implementation (TIDES), fixed before any trained-model result exists (\cref{sec:exp-real}); its results are \notrun.
\end{enumerate}

\section{Related Work}
\label{sec:related}

\paragraph{Discretization in structured SSMs.}
S4 discretizes with the bilinear transform and reports a test-time change of the sampling resolution obtained by changing its internal step size~\citep{gu2021s4}.
LSSL notes that irregularly spaced data can be handled by discretizing the same state matrix with a different timescale~\citep{gu2021lssl}.
S4D gives both bilinear and ZOH formulas for diagonal models~\citep{gu2022s4d}.
S5 uses ZOH, $\bar\Lambda=e^{\Lambda\Delta}$, $\bar B=\Lambda^{-1}(\bar\Lambda-I)\tilde B$, rescales $\Delta$ globally by the ratio of sampling rates for zero-shot 8\,kHz evaluation of a 16\,kHz Speech Commands model, and supplies a different $\Delta_t$ at each step for an irregularly sampled pendulum regression task, with ablations that drop the interval or append it as an input feature~\citep{smith2022s5}.
S4ND studies resolution change for images and notes that only the relative rate matters~\citep{nguyen2022s4nd}; event-camera SSMs study inference at a different frequency~\citep{zubic2024event}.
These works concern linear time-invariant (LTI) layers.

\paragraph{Selective SSMs and their discretization.}
Mamba makes $\Delta$, $B$ and $C$ functions of the input and states the ZOH rule~\citep{gu2023mamba}; Mamba-2 keeps the parameterization and discretization of Mamba~\citep{dao2024mamba2}.
Mamba-3 derives the ZOH form for time-varying systems with right-endpoint holding, formalizes the released rule $h_t=e^{\Delta_tA_t}h_{t-1}+\Delta_tB_tx_t$ as exponential-Euler, and proposes an exponential-trapezoidal rule with a data-dependent endpoint weight that is second order only if the weight is $\tfrac12+O(\Delta_t)$; its ablations prefer not enforcing that constraint~\citep{lahoti2026mamba3}.
Its evaluation concerns language modeling and related tasks, not sampling grids.
Liquid-S4 makes the transition input-dependent and discusses zero-shot 8\,kHz transfer~\citep{hasani2022liquid}.

\paragraph{Physical time in selective SSMs.}
TIDES keeps $\tilde\Delta\equiv\Delta$ physical, makes the real part of the eigenvalues and $B,C$ input-dependent, and uses the ZOH input matrix $\bar B_k=\Lambda_k^{-1}(\bar\Lambda_k-I)B_k$~\citep{soydan2026tides}.
Its Fading Flash diagnostic changes a global step $\Delta$ for sequences of fixed length and shows that a Mamba surrogate with $\Delta$ as an input channel fails outside the training range; its random-drop study removes observations while preserving timestamps and reports classification accuracy.
In the sections we read (method, Fading Flash, random drop, and the discretization and diagnostic appendices), it neither refines the grid of a fixed physical path nor decomposes output changes.
It is the closest prior work, and we treat its architecture as prior art, not as a baseline to beat.

\paragraph{Continuous-time sequence models.}
Neural CDEs are driven by a continuous interpolation of the observations (natural cubic splines in the original work) and target irregular time series~\citep{kidger2020ncde}; Log-NCDEs build on NCDEs, which are robust to irregular sampling and decouple the number of network evaluations from the number of observations~\citep{walker2024logncde}.
\citet{cirone2024theoretical} interpret selective SSMs as linear CDEs in a limit where a scalar $\delta$ plays the role of $dt$.
Oscillatory SSMs study implicit and implicit--explicit time integration of a second-order system~\citep{rusch2024linoss}.

\paragraph{Remaining difference.}
In the sources above we did not find a controlled refinement of the \emph{same} held path for selective SSMs that separates splitting from new observations, decomposes the change into entry points, and treats readouts and inter-layer resampling as entry points.
This is absence of evidence in the sources we read, not proof of novelty.

\section{Problem Setup}
\label{sec:setup}

\paragraph{Continuous-time model.}
We study a scalar-input selective model with $N$ diagonal modes,
\begin{equation}
\dot h_n(t)=g\big(u(t)\big)\big(\lambda_n h_n(t)+B_n(u(t))\,u(t)\big),\qquad y(t)=\mathrm{Re}\sum_{n}C_n(u(t))\,h_n(t),
\label{eq:ct}
\end{equation}
with $\mathrm{Re}\,\lambda_n<0$, a positive gate $g(u)=\mathrm{softplus}(wu+\beta)$ shared across modes (as $\Delta$ is shared across the state dimension in Mamba-style layers), and affine selective $B(u)$, $C(u)$.

\paragraph{Grids and holds.}
A grid is $0=t_0<\dots<t_K=T$ with steps $dt_k=t_k-t_{k-1}$ and mesh $\delta=\max_k dt_k$.
We use the right-endpoint hold $\tilde u(t)=u(t_k)$ on $(t_{k-1},t_k]$, which matches the recurrences of Mamba and of the TIDES code (the TIDES paper writes the left-endpoint form; its released scan uses the gap before step $k$).
A discrete variant is $h_k=\bar A_kh_{k-1}+\bar B_ku_k$ with $\Delta_k=dt_k\,g(u_k)$ (``$\Delta{=}dt\,g$'') or $\Delta_k=\tau g(u_k)$ with a fixed $\tau$ (``$\Delta{=}\tau g$'', a step that counts samples), and with one of three rules: exact ZOH ($\bar A=e^{\Delta\lambda}$, $\bar B=(e^{\Delta\lambda}-1)\lambda^{-1}B$), Euler-$B$ ($\bar A=e^{\Delta\lambda}$, $\bar B=\Delta B$), or bilinear.
We set $\tau$ to the base step, so $\Delta{=}\tau g$ and $\Delta{=}dt\,g$ coincide on the base grid.

\paragraph{Two grid changes.}
\emph{Splitting} divides every (or every selected) base interval into $m$ equal sub-steps that all receive the held value $u_k$; the right-held physical path is unchanged.
\emph{New observations} divide the intervals in the same way but give each new sub-time $s$ the value $u(s)$ of the continuous signal; the grids are nested, so the base times are common to all $m$.
Outputs are always compared at the common base times.

\paragraph{Exact decomposition.}
For a discrete variant with outputs $D_m$ at the base times of grid $m$, let $Y_m$ denote the continuous-time solution of \eqref{eq:ct} on the held path of grid $m$, evaluated at the same times.
The change $T_m=D_m-D_1$ splits exactly as
\begin{equation}
T_m=\underbrace{(Y_m-Y_1)}_{P_m:\ \text{path term}}+\underbrace{\big[(D_m-Y_m)-(D_1-Y_1)\big]}_{R_m:\ \text{artifact term}},
\label{eq:decomp}
\end{equation}
so $\|T_m\|^2=\|P_m\|^2+\|R_m\|^2+2\langle P_m,R_m\rangle$.
Under splitting, $P_m=0$ and the whole change is an artifact.
Under new observations, $P_m$ reflects genuine new external information about $u$.
Because the cross term can be large and of either sign, norms of $P_m$ and $R_m$ do not add up, and we never report a ratio of norms as a ``share'' of the change.

\paragraph{Readouts.}
For an output sequence $y_1,\dots,y_K$ we distinguish the \emph{sample-count} readouts $\sum_ky_k$ and $\frac1K\sum_ky_k$; two \emph{time-weighted endpoint sums}, the right-endpoint sum $\frac1T\sum_ky_k\,dt_k$ and the trapezoidal sum; and the \emph{exact held-path integral} $\frac1T\int_0^Ty(t)\,dt$, computed in closed form from the intra-step solution under the hold.
The exact integral is defined only for exact-ZOH states, because Euler-$B$ and bilinear steps have no exact intra-step trajectory.

\paragraph{Toy protocol.}
Each independent unit is one seed that fixes one parameter draw ($N{=}4$ real modes, $|\lambda_n|\in[0.2,2]$) and one input path (a sum of three sinusoids); grid variants of the same unit are not independent samples.
The primary configuration uses \NunitsPrimary{} units on a uniform base grid with $T{=}8$, $K{=}16$, and $m\in\{1,2,4,8\}$.
Nothing is trained, so no train/test split is involved.
Hypotheses, metrics, thresholds, budget (2 CPU threads, 120\,s) and stop conditions were fixed before the run; three amendments were recorded before any experiment was executed (\cref{app:prereg}).
References are computed independently of the ZOH code with classical RK4.

\section{Where Grid Dependence Enters: Analysis}
\label{sec:analysis}

\subsection{Single layer: the assumptions behind split invariance}
\label{sec:single}

\begin{proposition}[standard]
\label{prop:split}
Fix one base interval $(t_{k-1},t_k]$ and suppose
(i) the input is the held value $u_k$ on the whole interval, and every sub-step after splitting receives $u_k$;
(ii) every per-step coefficient ($g$, $B$, $C$, $\lambda$) is a function of the held value only;
(iii) the step is $\Delta=\text{(sub-step length)}\cdot g(u_k)$; and
(iv) $\bar A$ and $\bar B$ are the exact ZOH formulas.
Then, from the same state at $t_{k-1}$, the state and the output at $t_k$ are the same for every number $m$ of equal sub-steps; by induction over intervals, the outputs at all base times are split-invariant.
\end{proposition}
\begin{proof}
Under (i)--(iii) every sub-step integrates the same constant-coefficient ODE $\dot h=g(u_k)(\lambda h+B(u_k)u_k)$, and under (iv) each sub-step is its exact flow $\Phi_{s}$ over the sub-step length $s$. Flows compose, $\Phi_{s_1}\circ\Phi_{s_2}=\Phi_{s_1+s_2}$.
\end{proof}

The proposition is textbook; we state it to make the assumptions explicit, because each entry point below violates one of them.
Violating (iii) ($\Delta{=}\tau g$) turns $m$ sub-steps into $m$ times the decay, so the memory horizon is measured in samples.
Violating (iv) introduces a local error: for Euler-$B$, $|\Delta B u|\,|\varphi_1(\Delta\lambda)-1|\le|Bu|\,\Delta^2|\lambda|/2$ with $\varphi_1(z)=(e^z-1)/z$, a first-order global error (\cref{app:proofs}, unproved sketch).
Violating (ii) happens whenever a coefficient sees anything besides the held value, for example a token-indexed convolution over neighbouring samples (Mamba's \texttt{d\_conv}${=}4$ depthwise convolution), time or position features, state-dependent (``liquid'') transitions, or normalization statistics computed over the time axis during training.
We did not measure the convolution case (\cref{sec:limits}).

\paragraph{Bilinear: stability, oscillation and stiff decay are different properties.}
For $\mathrm{Re}\,z<0$ the bilinear transition $\bar A=(1+z/2)/(1-z/2)$ satisfies $|\bar A|<1$, so it is stable at every step size.
For real $z<-2$ it is negative, which produces sign-alternating transients that the exact solution does not have.
As $z\to-\infty$ it tends to $-1$ instead of $e^z\to0$, so stiff modes decay inaccurately (it is not L-stable).
Its fixed point under a held input, $-Bu/\lambda$, is exact.
\Cref{tab:stiff} separates these three properties.

\subsection{Several layers: internal resampling is not new information}
\label{sec:coupling}

In a stack, layer~2 is driven by the continuous output of layer~1.
A layerwise recurrence gives layer~2 only the endpoint samples of that signal, held over each step.
Splitting the input grid changes which internal samples layer~2 sees, although no external observation is added.
The minimal instance is the linear cascade
\begin{equation}
\dot h_1=-a h_1+b\,u(t),\qquad \dot h_2=-c\,h_2+d\,h_1(t),\qquad a,c>0.
\label{eq:cascade}
\end{equation}

\begin{proposition}[standard]
\label{prop:cascade}
Let $u$ be held on a grid with mesh $\delta$, $|u|\le U$, and $h_1(0)=h_2(0)=0$.
The exact coupled solution of \eqref{eq:cascade} at base times is invariant under splitting.
The layerwise computation that is exact in layer~1 and gives layer~2 the held value $h_1(t_k)$ on $(t_{k-1},t_k]$ has error $|e_k|\le |b\,d|\,U\,\delta\,e^{c\delta}/c$ at every grid time, for every $T$, including $a=c$.
\end{proposition}
\begin{proof}
The coupled system is linear with constant coefficients on each held interval, so invariance follows as in \cref{prop:split}.
For the layerwise error, layer~1 is exact, so with $\tau_k=dt_k$,
$e_k=e^{-c\tau_k}e_{k-1}+d\int_0^{\tau_k}e^{-c(\tau_k-s)}\big[h_1(t_k)-h_1(t_{k-1}+s)\big]ds$.
Since $|h_1|\le|b|U/a$, $|\dot h_1|\le 2|b|U$, and the bracket is at most $2|b|U(\tau_k-s)$, the local term is at most $|b\,d|U\tau_k^2$.
Unrolling with $e_0=0$ gives $|e_k|\le|b\,d|U\,\delta\sum_{j\le k}\tau_je^{-c(t_k-t_j)}\le|b\,d|U\,\delta\,e^{c\delta}/c$, where the sum is bounded by $e^{c\delta}\int_0^{t_k}e^{-c(t_k-s)}ds$.
\end{proof}

This is elementary numerical analysis; the proof is written out here but has not been checked by a third party.
The point is interpretive.
When all single-layer conditions of \cref{prop:split} hold in every layer, a stacked recurrence on the observation grid can still change under splitting, because the inter-layer signal is resampled.
This change is a reconstruction error of an \emph{internal} signal; calling it new information would be wrong.
It vanishes if the inter-layer signal is represented exactly (the coupled flow) or if the stack runs on a grid that does not depend on the observations.
Whether it matters in trained models is open (\cref{sec:exp-real}).

\subsection{Readouts}
\label{sec:readout-analysis}

Readouts are the last entry point.
The exact held-path integral is additive over sub-intervals, so under exact-ZOH states it is invariant under splitting.
Time-weighted endpoint sums converge to it only where the grid is refined; under a nonuniform refinement, the error from unrefined intervals remains.
Sample-count readouts weight samples, not time: the sample sum scales with the number of samples, and the sample mean converges to a density-weighted average rather than the time average.
These facts are elementary; the question is how large they are relative to the other entry points.

\section{Controlled Results}
\label{sec:exp}

All results in this section are from the fixed-parameter toys of \cref{sec:setup}.
They are numerical checks and controlled measurements, not proofs, and they say nothing directly about trained Mamba, S4, S5 or TIDES models.
The pre-registered FIRST\_RUN executed in \FirstRunSeconds\,s on 2 CPU threads; all data files were byte-identical between two executions (\cref{app:prereg}).

\subsection{Splitting a held interval}
\label{sec:exp-split}

\Cref{tab:split} and \cref{fig:convergence}(a) report the artifact against the exact held-path solution.
With $\Delta{=}dt\,g$ and exact ZOH, the output is split-invariant to $\EoneZohMax$ (maximum over units and $m$), and the exact ZOH code agrees with the independent RK4 reference to $\EoneRKmax$.
This is an engineering check of \cref{prop:split}, not a finding.
With the correct step, Euler-$B$ converges at first order (median slope $\EoneEulerSlope$), but its artifact at the base step is large in this toy (median $\EoneEulerMone$, still $\EoneEulerMeight$ at $m{=}8$); the magnitude depends on the toy's $\Delta|\lambda|$ scale and was not measured for any trained model.
Bilinear converges at second order (slope $\EoneBilinSlope$).
With $\Delta{=}\tau g$ the artifact does not vanish; it grows from $\EoneNodtMtwo$ at $m{=}2$ to $\EoneNodtMeight$ at $m{=}8$ (medians), and $\HfourEulerFrac$ of $32$ units are non-decreasing for the Euler-$B$ variant.
The $\Delta{=}\tau g$ variants are grid-dependent by construction; they illustrate a mechanism and are not evidence about Mamba itself.
On secondary configurations (jittered base grid; complex modes, 8 units each, descriptive only) the pattern is the same, except that bilinear with oscillatory modes changes more under splitting ($\EoneComplexBilin$ vs.\ $\EoneRealBilin$ for real modes at $m{=}8$); we did not test the cause.

\subsection{Adding new observations}
\label{sec:exp-newobs}

When new observations are added, the exact-ZOH artifact against RK4 on the new held path stays below $\EtwoZohArt$, so its whole output change equals the change of the continuous-time solution on the new path.
That change reflects new external information: the held path approaches the continuous signal, and the error to the continuous-time truth falls from $\EtwoHoldErrOne$ to $\EtwoHoldErrEight$ (median slope $\EtwoSlope$, first order as expected for a hold).
\Cref{tab:newobs} applies the exact decomposition \eqref{eq:decomp} to the other variants.

\subsection{Readouts and the interaction of fixes}
\label{sec:exp-readout}

\Cref{tab:readout} changes the observation density in the first half only.
With exact ZOH and $\Delta{=}dt\,g$, the backbone is split-invariant, yet the sample mean changes by $\EthreeMeanChange$ and the sample sum by $\EthreeSumChange$ (scale-normalized, $m{=}8$).
The trapezoidal and right-endpoint time-weighted sums change by $\EthreeTrapzChange$ and $\EthreeRiemannChange$; the exact held-path integral changes by $\EthreeExactChange$.
When new observations are added to the first half, the sample-mean error to the continuous-time average grows from $\EthreeMeanErrOne$ to $\EthreeMeanErrEight$, while the exact integral's error is $\EthreeExactErrEight$ at $m{=}8$; we expect this remaining error to come from the unrefined second half, but did not test it.

Two pre-registered readout checks did not come out cleanly.
The original clause H7c, which required the right-endpoint sum's change relative to $m{=}1$ to decrease with $m$, was mis-specified before the run: a readout that converges to a limit different from its $m{=}1$ value moves toward that limit.
It failed as predicted (slope $\HsevenOrigSlope$).
The restated clause, that the gap between the right-endpoint sum and the exact integral decreases, passed only weakly: median slope $\EthreeRMEslope$, with $\EthreeRMEneg$ of 32 units negative.
The likely cause is the unrefined half, whose coarse endpoint error does not shrink, but we did not test this separately.

\Cref{tab:interaction} applies one fix at a time to the Mamba-style toy recipe ($\Delta{=}\tau g$, Euler-$B$, sample mean; change $\FacNone$).
Exact ZOH alone does not help ($\FacZoh$); the physical step alone leaves $\FacDt$; a time-weighted readout alone leaves $\FacTime$.
Only the combination of the physical step, exact ZOH and the exact integral reaches $\FacAll$.
The fixes are therefore not additive, and we do not attribute percentages to them.
Under the pre-registered stop condition, this means the toy provides no support for a new architecture: simple time handling explains the entire single-layer artifact.
The stop condition is an operational decision rule; it is not a statistical test, an equivalence result or a novelty argument.

\subsection{Trained models}
\label{sec:exp-real}

No trained model has been evaluated; this subsection records a protocol fixed before any result (P1-REAL-01).
We fixed one official implementation before seeing results: TIDES at a pinned commit (MIT license), chosen because it is the authors' code, runs on CPU without custom kernels, and supports per-step physical steps natively.
The official Mamba code requires CUDA or Triton kernels for its standard paths, and the official S5 code pins 2022 JAX versions, so they were not selected for the first run.
We have not trained or run any of these models.

The task will be sequence regression of the toy teacher \eqref{eq:ct} (fixed parameters) on sine-sum inputs, with trajectory identifiers split into 512/128/256 train/dev/test \emph{before} any grid is built, labels at fixed physical query times, a fixed physical horizon, and normalization statistics from the training split only.
One model will be trained on a uniform grid and evaluated on the same test trajectories (i) on the native grid with physical step sizes and (ii) after causal resampling onto the training grid (last observation carried forward), under splitting, nested new observations, and random observation times.
We will report output discrepancy, task loss and inference cost with bootstrap intervals over test trajectories, and we will call a difference negligible only if the 95\% interval of the paired difference lies within a pre-specified $\pm5\%$ margin; a non-significant difference will not be read as equivalence.
The protocol predicts, from \cref{prop:cascade}, that the native two-block model will change under splitting beyond the float32 floor, and that resampling will be split-invariant by construction; these are predictions, not results.

Reading the pinned code (not running it) shows three places where \cref{sec:analysis} predicts grid dependence: two stacked blocks on the observation grid (\cref{sec:coupling}); a classifier head that averages over tokens, i.e.\ a sample-count readout; and the ZOH input matrix computed as $(\bar\Lambda-1)/\Lambda$ rather than with \texttt{expm1}, which loses relative precision for small $\Lambda\Delta$ in float32 (\cref{app:numerics}).

\section{Limitations}
\label{sec:limits}

\emph{Toy scope.} All measurements use fixed parameters, one input channel and sinusoidal inputs; the reported magnitudes, especially for Euler-$B$, depend on the toy's $\Delta|\lambda|$ scale and do not transfer to trained models.
\emph{No trained models.} Real Mamba, S4, S5 and TIDES results are \notrun; the protocol in \cref{sec:exp-real} is a plan.
\emph{Unmeasured entry points.} The token-indexed convolution of Mamba, normalization over the time axis, and stacks deeper than two linear layers were not measured.
\emph{Numerics.} float32 behaviour was emulated by rounding every primitive with a correctly rounded exponential; this does not reproduce any GPU kernel.
\emph{Analysis.} \Cref{prop:split,prop:cascade} are standard; the first-order bounds for the hold error and for Euler-$B$ in \cref{app:proofs} are unproved sketches.
\emph{Exploratory parts.} The exact decomposition of \cref{tab:newobs} and the stiffness columns of \cref{tab:stiff} are re-aggregations of already-seen results.
\emph{Pre-registration.} One readout clause was mis-specified and failed, and its restatement passed only weakly (\cref{sec:exp-readout}).
\emph{Literature.} For the three closest papers (TIDES, Mamba-3, S5) the key equations and experiment sections were read in the original text; the other entries were checked by keyword search of the full text and may be incomplete.

%=====================================================================================
\section{Conclusion}
\label{sec:conclusion}

Grid dependence in a selective SSM does not come from one place.
In our toys it enters through a step size that counts samples, through an inexact input-matrix discretization, through sample-count readouts, and, in stacks, through the resampling of internal signals.
A physical step, exact ZOH and an exact time-integral readout remove the single-layer splitting artifact completely, but only together, and they do not remove the inter-layer resampling error, which is first order in the step and carries no new information.
Because simple time handling suffices in a single layer and the physical-step selective design already exists, we do not propose an architecture.
The remaining question is empirical: how large each entry point is in trained models.

\section*{Impact Statement}

This paper presents work whose goal is to advance the field of Machine Learning, specifically the understanding of how sequence models respond to changes in sampling.
All experiments use synthetic data and small CPU computations.
The main practical risk we see is over-reading toy results: a model that looks sampling-consistent in a controlled toy may still behave differently on irregularly sampled real data, for example clinical or sensor streams, so any deployment in such settings would need evaluation on the actual data and sampling process.
We are not aware of other societal consequences that must be specifically highlighted here.

\section{Numerical floor}
\label{app:numerics}

\Cref{tab:numerics} shows that the naive coefficient $(e^{z}-1)/\lambda$ loses relative precision as $|z|$ shrinks ($\NoneNaive$ at $z{=}-10^{-14}$ in float64), while \texttt{expm1} stays at rounding level.
In float64 the effect on split composition is negligible for up to $65{,}536$ sub-steps.
In emulated float32, the composition drift reaches $\NfourFloor$ at $16{,}384$ sub-steps, so differences below about $10^{-4}$ are not interpretable in float32 experiments of this length.

\section{Proof sketches (unproved)}
\label{app:proofs}

\paragraph{Assumptions.}
(A1) $\mathrm{Re}\,\lambda_n\le-\mu<0$; (A2) $g:[-U,U]\to[g_{\min},g_{\max}]$ with $g_{\min}>0$ and Lipschitz constant $L_g$; (A3) $F(v)=g(v)B(v)v$ is $L_F$-Lipschitz with $|F|\le F_{\max}$; (A4) $u$ is $L_u$-Lipschitz with $|u|\le U$.

\paragraph{Hold error (UNPROVED sketch).}
Let $h_{\tilde u}$ and $h_u$ solve \eqref{eq:ct} driven by the held and the continuous input.
The error satisfies $\dot e=g(\tilde u)\lambda e+[(g(\tilde u)-g(u))\lambda h_u+F(\tilde u)-F(u)]$, the bracket is at most $(L_g|\lambda|H+L_F)L_u\delta$ with $H=F_{\max}/(g_{\min}\mu)$, and the propagator is bounded by $e^{-g_{\min}\mu(t-s)}$, which suggests $\sup_t|e(t)|\le(L_g|\lambda|H+L_F)L_u\delta/(g_{\min}\mu)$.
A complete proof must handle the discontinuous $\tilde u$ (Carathéodory solutions) and has not been written.
The toy's median slope $\EtwoSlope$ is consistent with first order; this is not a proof.

\paragraph{Euler-$B$ (UNPROVED sketch).}
With $z=\Delta\lambda$ and $\mathrm{Re}\,z\le0$, $e^z-1-z=z^2\int_0^1(1-s)e^{sz}ds$ gives the local bound $|\Delta Bu|\,|\varphi_1(z)-1|\le|Bu|\Delta^2|\lambda|/2$; summing against the contraction $e^{-g_{\min}\mu\,dt}$ suggests a global $O(\delta)$ bound uniform in $T$ whose constant grows with $\Delta|\lambda|$, consistent with the steady-state gain factor $\Delta|\lambda|/(1-e^{-\Delta|\lambda|})$ visible in \cref{tab:stiff}.

\paragraph{Refinement with $\Delta{=}\tau g$ (CONJECTURE).}
With $\Delta=\tau g$ fixed and step $\delta\to0$, the recurrence is the exact flow of the time-rescaled system $\dot h=(\tau/\delta)g(\tilde u)(\lambda h+B(\tilde u)\tilde u)$, whose solution should approach the memoryless quasi-steady state $-B(u)u/\lambda$; the artifact would then tend to a nonzero limit.

\section{Code facts of official implementations (read, not run)}
\label{app:code}

\begin{itemize}
  \item Mamba (\texttt{state-spaces/mamba} at the commit pinned in our records): the reference scan computes \texttt{deltaA = exp(delta*A)} and \texttt{deltaB\_u = delta*B*u}; the block applies a depthwise causal \texttt{Conv1d} with \texttt{d\_conv=4} before the SSM; \texttt{dt} is \texttt{softplus} of a projection plus a bias initialized so that \texttt{softplus(bias)} lies in $[0.001,0.1]$; the Mamba-3 module imports Triton kernels.
  \item TIDES (pinned commit): the step is \texttt{step\_scale * exp(log\_step)}; the ZOH input matrix is \texttt{(1/Lambda)*(Lambda\_bar-1)*B}; the scan is $x_k=\bar\Lambda_kx_{k-1}+\bar B_ku_k$ with the gap before step $k$; each block applies \texttt{BatchNorm1d(affine=False)} over batch and time; an optional causal convolution defaults to off; the classifier pools with \texttt{h.mean(dim=1)}.
  \item S5 (official JAX code): ZOH as in the paper with a static learned step; per-step intervals are used on a separate branch; CPU requirements pin \texttt{jax==0.3.5}.
\end{itemize}
These facts come from reading source files; their effect on any trained model is \notrun.
